# 🚀 Taner Şengül — Minimalist Monochrome Kişisel Portfolyo

Sade, şık, göz yormayan **siyah & beyaz (monochrome)** renk paletine sahip, samimi ve sosyal tonda geliştirilmiş modern kişisel web sitesi. **Next.js 16 (App Router)**, **Tailwind CSS v4** ve **TypeScript** altyapısıyla çalışmaktadır.

---

## ✨ Güncel Tasarım ve Özellikler

- 🌓 **Sade Siyah & Beyaz Tema (Pure Black & White):** Neon ve doygun renklerden tamamen arındırılmış; saf beyaz, koyu siyah ve minimalist gri tonlarında çift tema.
- 💬 **Sosyal & Samimi Ton:** Doğrudan iş ilanı/CV havası yerine teknoloji merakınızı, Vibe Coding tutkunuzu ve projelerinizi anlatan samimi bir yaklaşım.
- 🚫 **Gizlilik Odaklı:** İkametgah bilgisi ve telefon numarası siteden tamamen kaldırılmıştır.
- 📱 **Mobil ve Masaüstü Uyumlu:** Sadeleştirilmiş menü yapısı (Hakkımda, Yolculuğum, Yetenekler, Projeler, İletişim).
- 🧩 **Seçilmiş Projeler:** NoteGenius (AI Doküman Uygulaması) ve İksir Atölyesi (Mobil Oyun) için detaylı vaka analizi modalı.
- ✉️ **İletişim & Sosyal Medya:** Doğrudan e-posta kopyalama, GitHub ve LinkedIn kartları ve hızlı mesaj formu.

---

## 🛠️ Yerel Çalıştırma

```bash
# Geliştirici sunucusunu başlat:
npm run dev

# Üretim derlemesi oluştur ve test et:
npm run build
npm run start
```
Tarayıcınızdan `http://localhost:3000` (veya `http://localhost:3001`) adresine gidebilirsiniz.
